L'API du journal

fichiers JSON publics, sans clé

Chaque édition est publiée en JSON à côté du site. Aucune clé, aucun compte : un simple GET suffit, depuis un script, une appli ou un autre site (CORS ouvert par GitHub Pages).

Adresse de base

https://seigneur-seven.github.io/News.github.io/

Si le dépôt est renommé Seigneur-Seven.github.io, l'adresse devient https://seigneur-seven.github.io/.

Les points d'accès

CheminContenu
api/latest.jsonLa dernière édition : date, numéro, liens vers le JSON complet et le PDF.
api/editions.jsonL'index de toutes les éditions, de la plus récente à la plus ancienne, avec les titres d'information.
api/editions/AAAA-MM-JJ.jsonUne édition complète : culture, offres, mots, tech, GitHub, 5 sujets d'information, Sénat, ville.
pdf/Seven-News-AAAA-MM-JJ.pdfLe journal mis en page, prêt à imprimer.

Exemples

curl -s https://seigneur-seven.github.io/News.github.io/api/latest.json
import requests
base = "https://seigneur-seven.github.io/News.github.io/"
derniere = requests.get(base + "api/latest.json", timeout=30).json()
edition = requests.get(base + derniere["json"], timeout=30).json()
for sujet in edition["infos"]:
    print(sujet["theme"], "-", sujet["titre"])
const base = "https://seigneur-seven.github.io/News.github.io/";
const derniere = await (await fetch(base + "api/latest.json")).json();
const edition = await (await fetch(base + derniere.json)).json();
console.log(edition.offres.slice(0, 5));

Format de latest.json

{
  "date": "2026-10-06",
  "numero": 1,
  "json": "api/editions/2026-10-06.json",
  "pdf": "pdf/Seven-News-2026-10-06.pdf",
  "mise_a_jour": "2026-10-06T20:00:00+02:00"
}

Champs d'une édition

  • culture : citation et blocs de culture générale
  • offres : stages triés par salaire (salaire_mensuel_usd, lien…)
  • mots : mots du jour (registre : soutenu ou argot)
  • tech, github : actualité tech et dépôts à suivre
  • infos[] : faits numérotés, chiffres, chronologie, gauche / droite, incertain, verification, sources
  • senat : votes, composition, textes à venir
  • ville : actualité et sorties à Cergy et alentour

Bon à savoir

  • Mise à jour une fois par jour, vers 20 h (heure de Paris).
  • Fichiers statiques : pas de filtre côté serveur, filtre côté client.
  • Les numéros entre crochets d'un fait renvoient à la position dans sources (à partir de 1).
